# Intro to Systems Programming Coursework

This repository contains selected coursework projects from an Intro to Systems Programming course.

The projects focus on C, C++, object-oriented programming, data structures, memory management, templates, exceptions, file I/O, and Python scripting.

## Projects

### EX01 - Israeli Queue Data Structure
A generic C queue implementation where insertion order is affected by friendship and rivalry rules.

### EX02 - Basic Mtmchkin Game
A simplified C++ card game that introduces object-oriented design through players, cards, and game state.

### EX03 - HealthPoints and Generic Queue
A C++ implementation of a bounded health-points class and a generic queue template.

### EX04 - Full Mtmchkin Game
A larger C++ OOP card game with multiple player classes, card types, file-based deck loading, exceptions, and game-state management.

### EX05 - Python Encryption System
A Python encryption and decryption system supporting Caesar and Vigenere ciphers using JSON configuration and file processing.
